# Várias Famílias

**Está fora do escopo:** atender mais de uma família no mesmo banco de dados.

O app é simples e feito para uma família. Não há cadastro de famílias nem separação de dados entre
grupos: todos os membros veem e registram no mesmo conjunto de dados, e o
[Início](../03-funcionalidades/01-principal/01-inicio.md) mostra os números dessa família.
